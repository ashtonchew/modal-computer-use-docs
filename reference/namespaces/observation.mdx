The observation namespaces let you inspect the state of the Sandbox desktop without modifying it. You can capture full or partial screenshots, query the display geometry, enumerate and manage X11 windows, check browser status, inspect named background processes, control the desktop session lifecycle, and retrieve debug URLs for VNC access. These namespaces are available on `ComputerSandbox`, `AsyncComputerSandbox`, and `AsyncDaemonClient`.

<Note>
All methods shown here are available as `async` counterparts. The async versions are identical in signature but must be awaited.
</Note>

---

## computer.screenshots

The `computer.screenshots` namespace captures images of the desktop, selected regions, or zoomed views.

### `full(...)`

Captures a full-resolution screenshot of the entire desktop.

<ParamField path="format" type='"png" | "jpeg" | "webp"' default='"png"'>
  Image encoding format.
</ParamField>

<ParamField path="quality" type="int" default="90">
  Compression quality for JPEG and WebP. Ignored for PNG.
</ParamField>

<ParamField path="scale" type="float" default="1.0">
  Output scale factor relative to the native display resolution.
</ParamField>

<ParamField path="show_cursor" type="bool" default="false">
  Include the cursor in the screenshot.
</ParamField>

<ParamField path="processing" type='"daemon" | "client" | "auto"' default='"auto"'>
  Where image encoding is performed. `"auto"` lets the daemon decide.
</ParamField>

<ParamField path="storage" type='"inline" | "artifact" | "auto"' default='"inline"'>
  Where the screenshot is stored. `"inline"` returns the bytes in the response body. `"artifact"` saves to the artifact store. `"artifact"` and `"auto"` count against screenshot and artifact budgets.
</ParamField>

**Returns** `Screenshot`.

```python
screenshot = await computer.screenshots.full()
screenshot.save("desktop.png")

# Include cursor, JPEG encoding
screenshot = await computer.screenshots.full(
    format="jpeg", quality=85, show_cursor=True
)
```

To retrieve raw image bytes without a `Screenshot` wrapper, use `full_bytes()` with the same parameters (except `storage`).

---

### `region(x, y, width, height, ...)`

Captures a rectangular crop of the desktop.

<ParamField path="x" type="int" required>
  Left edge of the region in pixels.
</ParamField>

<ParamField path="y" type="int" required>
  Top edge of the region in pixels.
</ParamField>

<ParamField path="width" type="int" required>
  Width of the region in pixels.
</ParamField>

<ParamField path="height" type="int" required>
  Height of the region in pixels.
</ParamField>

<ParamField path="format" type='"png" | "jpeg" | "webp"' default='"png"'>
  Image encoding format.
</ParamField>

<ParamField path="quality" type="int" default="90">
  Compression quality for JPEG and WebP.
</ParamField>

<ParamField path="scale" type="float" default="1.0">
  Output scale factor.
</ParamField>

<ParamField path="show_cursor" type="bool" default="false">
  Include the cursor in the capture.
</ParamField>

<ParamField path="processing" type='"daemon" | "client" | "auto"' default='"auto"'>
  Where encoding is performed.
</ParamField>

<ParamField path="storage" type='"inline" | "artifact" | "auto"' default='"inline"'>
  Where the screenshot is stored.
</ParamField>

**Returns** `Screenshot`.

```python
# Capture a 200×150 region starting at (50, 80)
screenshot = await computer.screenshots.region(50, 80, 200, 150)
```

Use `region_bytes()` to get raw bytes with the same positional and image-format parameters (except `storage`).

### `zoom(region, scale=2.0, ...)`

Captures a region and scales it up, producing a zoomed view useful for inspecting fine UI details.

<ParamField path="region" type="Region" required>
  A `Region` object with `x`, `y`, `width`, and `height` fields defining the area to zoom.
</ParamField>

<ParamField path="scale" type="float" default="2.0">
  Zoom factor applied to the captured region.
</ParamField>

<ParamField path="format" type='"png" | "jpeg" | "webp"' default='"png"'>
  Image encoding format.
</ParamField>

<ParamField path="quality" type="int" default="90">
  Compression quality for JPEG and WebP.
</ParamField>

<ParamField path="show_cursor" type="bool" default="true">
  Include the cursor in the zoomed capture.
</ParamField>

<ParamField path="storage" type='"inline" | "artifact" | "auto"' default='"inline"'>
  Where the screenshot is stored.
</ParamField>

**Returns** `Screenshot`.

```python
from modal_computer_use.models import Region

screenshot = await computer.screenshots.zoom(
    Region(x=300, y=200, width=100, height=80),
    scale=3.0,
)
```

---

### `zoom_around(center, width, height, ...)`

Convenience wrapper around `zoom()` that computes the region from a center point.

<ParamField path="center" type="tuple[int, int]" required>
  Center point `(x, y)` of the region to zoom.
</ParamField>

<ParamField path="width" type="int" required>
  Width of the region to capture before scaling.
</ParamField>

<ParamField path="height" type="int" required>
  Height of the region to capture before scaling.
</ParamField>

<ParamField path="scale" type="float" default="2.0">
  Zoom factor.
</ParamField>

<ParamField path="show_cursor" type="bool" default="true">
  Include the cursor in the capture.
</ParamField>

**Returns** `Screenshot`.

```python
screenshot = await computer.screenshots.zoom_around(
    center=(640, 400), width=120, height=80, scale=2.0
)
```

---

### Screenshot object

`Screenshot` is the return type of all `computer.screenshots` methods.

<ResponseField name="width" type="int">
  Width of the screenshot in pixels.
</ResponseField>

<ResponseField name="height" type="int">
  Height of the screenshot in pixels.
</ResponseField>

<ResponseField name="sha256" type="str">
  SHA-256 hex digest of the image bytes.
</ResponseField>

<ResponseField name="data" type="bytes | None">
  Raw image bytes when `storage="inline"`. `None` when stored as an artifact.
</ResponseField>

<ResponseField name="artifact_uri" type="str | None">
  Artifact URI when `storage="artifact"` or `"auto"`. `None` for inline captures.
</ResponseField>

```python
screenshot = await computer.screenshots.full()
with open("out.png", "wb") as f:
    f.write(screenshot.data)
```

## computer.display

The `computer.display` namespace exposes metadata about the virtual display.

### `info()`

Returns the display geometry and DPI.

**Returns** `DisplayInfo`.

<ResponseField name="width" type="int">
  Display width in pixels.
</ResponseField>

<ResponseField name="height" type="int">
  Display height in pixels.
</ResponseField>

<ResponseField name="dpi" type="int">
  Display DPI.
</ResponseField>

```python
info = await computer.display.info()
print(f"Display: {info.width}×{info.height} at {info.dpi} DPI")
```

## computer.windows

The `computer.windows` namespace lists and manages X11 windows.

### `list()`

Returns all open X11 windows.

**Returns** `list[X11Window]`.

---

### `active()`

Returns the currently focused window, or `None` if no window has focus.

**Returns** `X11Window | None`.

---

### `activate(window_id)`

Gives focus to the specified window.

<ParamField path="window_id" type="str" required>
  The X11 window ID string as returned by `list()` or `active()`.
</ParamField>

**Returns** `ActionResult`.

---

### `close(window_id)`

Sends a close request to the specified window.

<ParamField path="window_id" type="str" required>
  The X11 window ID string.
</ParamField>

**Returns** `ActionResult`.

---

### `wait_for(title_regex=None, class_name=None, pid=None, timeout=10.0)`

Blocks until a window matching the given criteria appears, then returns it.

<ParamField path="title_regex" type="str | None" default="None">
  Regular expression matched against the window title.
</ParamField>

<ParamField path="class_name" type="str | None" default="None">
  Exact match against the window class name.
</ParamField>

<ParamField path="pid" type="int | None" default="None">
  Filter by process ID.
</ParamField>

<ParamField path="timeout" type="float" default="10.0">
  Maximum seconds to wait before raising an error.
</ParamField>

**Returns** `X11Window`.

```python
# Wait for a dialog with "Save" in its title
window = await computer.windows.wait_for(title_regex=".*Save.*", timeout=15.0)
```

---

### X11Window object

<ResponseField name="id" type="str">
  X11 window identifier.
</ResponseField>

<ResponseField name="title" type="str">
  Window title bar text.
</ResponseField>

<ResponseField name="class_name" type="str">
  X11 window class name (WM_CLASS).
</ResponseField>

<ResponseField name="geometry" type="dict">
  Window position and size: `x`, `y`, `width`, `height`.
</ResponseField>

## computer.browser

The `computer.browser` namespace controls the configured browser process.

### `open_url(url, wait_for_window=True)`

Opens a URL in the configured browser.

<ParamField path="url" type="str" required>
  URL to open. Treat this as secret-bearing if it contains tokens or session identifiers.
</ParamField>

<ParamField path="wait_for_window" type="bool" default="true">
  Block until the browser window appears after opening the URL.
</ParamField>

**Returns** `ActionResult`.

```python
await computer.browser.open_url("https://example.com")
```

---

### `status()`

Returns the browser's current readiness status as a dictionary.

**Returns** `dict[str, Any]`.

---

### `render_metrics(url, timeout_seconds=30.0)`

Requests performance metrics for rendering a URL. Useful for benchmarking page load times.

<ParamField path="url" type="str" required>
  URL to render and measure.
</ParamField>

<ParamField path="timeout_seconds" type="float" default="30.0">
  How long to wait for metrics before timing out.
</ParamField>

**Returns** `dict[str, Any]` — timing and rendering metrics for the last render.

## computer.processes

The `computer.processes` namespace inspects and manages named background processes that the daemon supervises.

Named processes include: `xvfb` (the virtual framebuffer), `xfce` (the window manager), `x11vnc` (the VNC server, when enabled), and `browser` (the configured browser, when prewarmed).

### `status(name)`

Returns the current status of a named process.

<ParamField path="name" type="str" required>
  Process name (for example `"xvfb"`, `"browser"`).
</ParamField>

**Returns** `ProcessStatus` — includes fields such as `name`, `running`, `pid`, and `exit_code`.

---

### `restart(name)`

Restarts a named process.

<ParamField path="name" type="str" required>
  Process name to restart.
</ParamField>

**Returns** `ProcessStatus` — the status after the restart attempt.

---

### `logs(name, tail=200)`

Returns the most recent stdout log lines from a named process.

<ParamField path="name" type="str" required>
  Process name.
</ParamField>

<ParamField path="tail" type="int" default="200">
  Maximum number of lines to return.
</ParamField>

**Returns** `str`.

---

### `stderr(name, tail=200)`

Returns the most recent stderr output from a named process.

<ParamField path="name" type="str" required>
  Process name.
</ParamField>

<ParamField path="tail" type="int" default="200">
  Maximum number of lines to return.
</ParamField>

**Returns** `str`.

---

### `errors(name, tail=200)`

Alias for `stderr()`. Returns structured error records from a named process.

<ParamField path="name" type="str" required>
  Process name.
</ParamField>

<ParamField path="tail" type="int" default="200">
  Maximum number of lines to return.
</ParamField>

**Returns** `str`.

```python
# Check if the browser is running
status = await computer.processes.status("browser")
if not status.running:
    await computer.processes.restart("browser")

# Tail browser stderr for crash diagnostics
stderr = await computer.processes.stderr("browser", tail=50)
print(stderr)
```

## computer.lifecycle

The `computer.lifecycle` namespace controls the daemon-managed desktop session.

### `start()`

Starts the desktop session.

**Returns** `LifecycleResult`.

### `stop()`

Stops the desktop session.

**Returns** `LifecycleResult`.

### `restart()`

Restarts the desktop session.

**Returns** `LifecycleResult`.

### `status()`

Returns the current desktop status, including a budget snapshot for actions, screenshots, artifact bytes, and recording seconds.

**Returns** `ComputerStatus`.

```python
status = await computer.lifecycle.status()
print(status)
```

## computer.debug

The `computer.debug` namespace exposes debug endpoints. Use these during development, not in production automation.

### `urls()`

Returns all available debug URLs.

**Returns** `DebugUrls`.

<ResponseField name="vnc" type="str | None">
  noVNC URL when VNC is enabled (`expose_vnc != "off"`). Treat as secret-bearing.
</ResponseField>

<Warning>
For Modal-created Sandboxes, prefer `ComputerSandbox.debug_urls()` over `computer.debug.urls()` to get the Modal-owned noVNC URL. The daemon-level helper only knows the daemon-side URL, which may differ from the URL Modal exposes publicly.
</Warning>

---

### `vnc_url(refresh=False)`

Returns the noVNC URL when VNC is enabled, or `None` when VNC is off.

<ParamField path="refresh" type="bool" default="false">
  Force a refresh of the cached URL.
</ParamField>

**Returns** `str | None`.

```python
vnc = await computer.debug.vnc_url()
if vnc:
    print(f"Connect to VNC: {vnc}")
```
