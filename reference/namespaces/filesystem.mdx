The filesystem namespaces give you read/write access to files inside the Sandbox, the ability to run shell commands, launch desktop applications, manage screen recordings, and query session metadata. All artifact operations go through the daemon's managed store, so paths are normalized and budget accounting is applied automatically. Command execution is serialized under the daemon's input lock so that GUI-affecting tools like `xdotool` do not race with concurrent action batches.

<Note>
All methods shown here are available as `async` counterparts on `AsyncComputerSandbox` and `AsyncDaemonClient`. The async versions are identical in signature but must be awaited.
</Note>

---

## computer.artifacts

The `computer.artifacts` namespace manages files in the daemon's artifact store, rooted at `storage.artifacts_dir` (default `/home/desktop/artifacts`). All paths are relative to that root and are normalized by the daemon.

### `list(prefix="")`

Lists artifacts in the store, optionally filtered by a path prefix.

<ParamField path="prefix" type="str" default='""'>
  Optional path prefix to filter results. An empty string lists all artifacts.
</ParamField>

**Returns** `list[ArtifactInfo]`.

```python
artifacts = await computer.artifacts.list()
for a in artifacts:
    print(a.path, a.size)
```

---

### `read_bytes(path)`

Reads the raw bytes of an artifact file.

<ParamField path="path" type="str" required>
  Artifact path relative to `artifacts_dir`.
</ParamField>

**Returns** `bytes`.

```python
data = await computer.artifacts.read_bytes("report.pdf")
```

---

### `write_bytes(path, data, content_type=None)`

Writes raw bytes to an artifact path, creating or replacing the file.

<ParamField path="path" type="str" required>
  Destination artifact path relative to `artifacts_dir`.
</ParamField>

<ParamField path="data" type="bytes" required>
  Raw bytes to write. Artifact uploads are streamed and are not subject to the 16 MiB JSON body limit.
</ParamField>

<ParamField path="content_type" type="str | None" default="None">
  MIME type of the file. Defaults to `"application/octet-stream"` when not specified.
</ParamField>

**Returns** `ArtifactInfo` — metadata for the written file.

```python
await computer.artifacts.write_bytes("output.json", b'{"result": 42}', content_type="application/json")
```

---

### `download(path, local_path)`

Downloads an artifact to a local filesystem path.

<ParamField path="path" type="str" required>
  Artifact path relative to `artifacts_dir`.
</ParamField>

<ParamField path="local_path" type="str | Path" required>
  Local file path where the artifact will be saved.
</ParamField>

**Returns** `Path` — the resolved local path.

```python
from pathlib import Path

saved = await computer.artifacts.download("report.pdf", Path("./downloads/report.pdf"))
```

---

### `upload(local_path, path)`

Uploads a local file to the artifact store.

<ParamField path="local_path" type="str | Path" required>
  Local file path to read.
</ParamField>

<ParamField path="path" type="str" required>
  Destination artifact path relative to `artifacts_dir`.
</ParamField>

**Returns** `ArtifactInfo` — metadata for the uploaded file.

```python
await computer.artifacts.upload("./local-config.json", "config/config.json")
```

---

### `delete(path)`

Deletes an artifact from the store.

<ParamField path="path" type="str" required>
  Artifact path relative to `artifacts_dir`.
</ParamField>

**Returns** `None`.

---

### `manifest(prefix="")`

Lists artifacts with their hashes and sizes. Equivalent to `list()` but explicitly signals intent to inspect content integrity.

<ParamField path="prefix" type="str" default='""'>
  Optional path prefix to filter results.
</ParamField>

**Returns** `list[ArtifactInfo]`.

---

### `sync()`

Persists the artifact store to a Modal Volume. In the built-in local/daemon store without persistent storage configured, this is a no-op that reports `persistent=false`. With persistent storage configured, it reports `ok=true` only after the persistence operation succeeds.

**Returns** `ArtifactSyncResult`.

<ResponseField name="ok" type="bool">
  `true` if persistence succeeded; `false` if persistence is not configured or failed.
</ResponseField>

<ResponseField name="persistent" type="bool">
  `true` if the store is configured with a persistent backing Volume.
</ResponseField>

```python
result = await computer.artifacts.sync()
if not result.persistent:
    print("Artifacts are not persisted across sessions.")
```

---

### ArtifactInfo object

<ResponseField name="path" type="str">
  Artifact path relative to `artifacts_dir`.
</ResponseField>

<ResponseField name="size" type="int">
  File size in bytes.
</ResponseField>

<ResponseField name="sha256" type="str">
  SHA-256 hex digest of the file contents.
</ResponseField>

<ResponseField name="modified_at" type="str">
  ISO 8601 timestamp of the last modification.
</ResponseField>

## computer.recordings

The `computer.recordings` namespace manages screen recordings of the Sandbox desktop. Recordings are stored as artifacts and count against both the `max_recording_seconds` and `max_artifact_bytes` budgets.

### `start(name=None, fps=12, format="mp4")`

Begins a new screen recording.

<ParamField path="name" type="str | None" default="None">
  Optional name for the recording. When `None`, the daemon generates a name automatically.
</ParamField>

<ParamField path="fps" type="int" default="12">
  Frames per second for the recording.
</ParamField>

<ParamField path="format" type="str" default='"mp4"'>
  Output container format.
</ParamField>

**Returns** `Recording` — the recording metadata including its ID.

```python
recording = await computer.recordings.start(name="session-capture", fps=15)
print(f"Started recording: {recording.name}")
```

---

### `stop(recording_id)`

Finalizes and stops an active recording.

<ParamField path="recording_id" type="str" required>
  The recording ID returned by `start()`.
</ParamField>

**Returns** `Recording` — updated metadata including final size and duration.

---

### `list()`

Lists all recordings for the current session.

**Returns** `list[Recording]`.

---

### `get(recording_id)`

Returns metadata for a single recording.

<ParamField path="recording_id" type="str" required>
  The recording ID.
</ParamField>

**Returns** `Recording`.

---

### `download(recording_id, local_path)`

Downloads a recording to a local path.

<ParamField path="recording_id" type="str" required>
  The recording ID.
</ParamField>

<ParamField path="local_path" type="str | Path" required>
  Local file path to save the recording.
</ParamField>

**Returns** `Path` — the resolved local path.

```python
await computer.recordings.download(recording.name, "./session-capture.mp4")
```

---

### `delete(recording_id)`

Deletes a recording and its associated artifact.

<ParamField path="recording_id" type="str" required>
  The recording ID.
</ParamField>

**Returns** `None`.

---

### Recording object

<ResponseField name="name" type="str">
  Recording name or generated identifier.
</ResponseField>

<ResponseField name="artifact_uri" type="str | None">
  Artifact URI for the recording file within the artifact store.
</ResponseField>

<ResponseField name="size" type="int | None">
  File size in bytes after finalization.
</ResponseField>

<ResponseField name="duration" type="float | None">
  Recording duration in seconds after finalization.
</ResponseField>

<ResponseField name="sha256" type="str | None">
  SHA-256 hex digest of the recording file.
</ResponseField>

<ResponseField name="status" type="str">
  Recording status: `"recording"`, `"stopped"`, or `"error"`.
</ResponseField>

<ResponseField name="ffmpeg_args" type="list[str] | None">
  FFmpeg arguments used for this recording.
</ResponseField>

<ResponseField name="return_code" type="int | None">
  FFmpeg process exit code after the recording stops.
</ResponseField>

<ResponseField name="stderr_tail" type="str | None">
  Bounded tail of FFmpeg stderr output, available when a recording fails or emits diagnostics.
</ResponseField>

<ResponseField name="error" type="str | None">
  Structured error message when the recording failed.
</ResponseField>

## computer.commands

The `computer.commands` namespace runs arbitrary shell commands inside the Sandbox. Commands are serialized under the daemon's input lock because callers can invoke GUI-affecting tools such as `xdotool`.

### `run(*command, timeout=30.0)`

Runs a command vector inside the Sandbox.

<ParamField path="command" type="str (variadic)" required>
  Command and arguments. The first element is the executable; subsequent elements are arguments. Must contain at least one element. The default cap is `65,536` arguments (configurable via `COMPUTER_USE_MAX_COMMAND_ARGUMENTS`). Each argument is also bounded by the Linux encoded-byte limit.
</ParamField>

<ParamField path="timeout" type="float" default="30.0">
  Maximum seconds to wait for the command to complete.
</ParamField>

**Returns** `ActionResult` — contains the exit code and output.

<Warning>
`stdout` and `stderr` are sanitized before the daemon returns them. Known secret-bearing substrings—including bearer tokens, noVNC URLs, and artifact URIs—are redacted. Do not rely on these fields for security-sensitive string matching.
</Warning>

```python
result = await computer.commands.run("ls", "-la", "/home/desktop")
print(result)

# Run a Python script
result = await computer.commands.run("python3", "-c", "print('hello')", timeout=10.0)
```

## computer.apps

The `computer.apps` namespace launches desktop applications and opens artifact files with their default applications.

### `launch(command, args=None)`

Launches a desktop application by its command name.

<ParamField path="command" type="str" required>
  Application command or executable name (for example `"gedit"`, `"libreoffice"`, `"xterm"`).
</ParamField>

<ParamField path="args" type="list[str] | None" default="None">
  Additional arguments passed to the application. Subject to the same `65,536`-argument default cap as commands.
</ParamField>

**Returns** `ActionResult`.

```python
await computer.apps.launch("gedit")
await computer.apps.launch("libreoffice", args=["--writer", "/home/desktop/artifacts/doc.odt"])
```

---

### `open_artifact(path)`

Opens an artifact file using its default desktop application (via `xdg-open`).

<ParamField path="path" type="str" required>
  Artifact path relative to `artifacts_dir`.
</ParamField>

**Returns** `ActionResult`.

```python
# Open a PDF artifact in the default viewer
await computer.apps.open_artifact("report.pdf")
```

## computer.session

The `computer.session` namespace exposes metadata about the current Sandbox session.

### `metadata()`

Returns metadata about the Sandbox and session. This includes Modal-provided information when available.

**Returns** `SandboxRef`.

<ResponseField name="id" type="str | None">
  Modal Sandbox identifier.
</ResponseField>

<ResponseField name="app_name" type="str | None">
  Modal app name the Sandbox belongs to.
</ResponseField>

<ResponseField name="name" type="str | None">
  Named Sandbox identifier, if the Sandbox was created or attached with a name.
</ResponseField>

<ResponseField name="run_id" type="str | None">
  Run correlation identifier.
</ResponseField>

<ResponseField name="owner" type="str | None">
  Owner identifier.
</ResponseField>

<ResponseField name="creation_time" type="str | None">
  ISO 8601 timestamp when the Sandbox was created.
</ResponseField>

<ResponseField name="config_hash" type="str | None">
  Hash of the `ComputerConfig` used at creation time. Used by `attach_or_create()` for compatibility verification.
</ResponseField>

<ResponseField name="tags" type="dict | None">
  Modal Sandbox tags.
</ResponseField>

<ResponseField name="artifact_dir" type="str | None">
  Absolute path of the artifact directory inside the Sandbox.
</ResponseField>

```python
meta = await computer.session.metadata()
print(f"Sandbox ID: {meta.id}")
print(f"Run ID: {meta.run_id}")
print(f"Artifacts at: {meta.artifact_dir}")
```

---

### `refresh()`

Refreshes the session state and returns updated metadata.

**Returns** `SandboxRef`.

<Tip>
Call `refresh()` after a lifecycle restart or after a period of inactivity to ensure the session metadata reflects the current state of the Sandbox.
</Tip>
