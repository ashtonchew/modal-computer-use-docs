## Keep latency terms separate

| Term | Starts | Ends |
| --- | --- | --- |
| Cold allocation | Before Sandbox creation | Modal allocates the Sandbox |
| Startup | After allocation | Daemon, desktop, auth, and required readiness complete |
| Borrow | Before lease setup | Placed client and lease are ready |
| Action to immediate frame | Before Step request | Valid Step result is decoded |
| First visual change | After action | Pixel verification confirms a changed frame or times out |
| Application readiness | Application-defined | Application-defined |

The stable Step contract ends at the immediate frame. First visual change is experimental. Application readiness needs an application-specific signal.

## X11 shared-memory evidence

MSS remains the production screenshot source. The optional X11 shared-memory source failed its fixed promotion gate because repeated readiness measurements included capture timeouts. Keep rejected artifacts and timeout attribution with any future rerun. A short operational green run cannot replace a full promotion result.

## Cost evidence

Cost estimates use recorded resource duration and list rates. Invoice reconciliation requires any
unmeasured image builds, storage, network, model usage, plan fees, credits, and taxes.
