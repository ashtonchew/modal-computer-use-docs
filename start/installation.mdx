---

You need Python 3.12 or later and Modal 1.5.3 or later.

## Install the package

```bash
uv add "modal-computer-use[modal]==2.0.0"
```

Use `pip` when your project does not use `uv`:

```bash
python -m pip install "modal-computer-use[modal]==2.0.0"
```

The base package loads Modal lazily when a lifecycle operation needs it.

## Set up Modal credentials

```bash
uv run modal setup
uv run modal environment list
```

Keep Modal credentials out of source files and shell transcripts.

## Choose optional provider extras

| Provider | Command |
| --- | --- |
| OpenAI | `uv add "modal-computer-use[modal,openai]==2.0.0"` |
| Anthropic | `uv add "modal-computer-use[modal,anthropic]==2.0.0"` |

The provider adapters translate actions and results. Your application owns provider credentials,
model calls, conversation state, and approval policy.

## Verify the install

```bash
uv run python -c "import modal_computer_use; assert modal_computer_use.__version__ == '2.0.0'"
uv run computer-use --help
```
