## Requirements

You need Python 3.12 or later. The Modal integration supports the Modal 1.5 line and requires Modal 1.5.2 or later.

## Install the package

Install the package with `uv`:

```bash
uv add "modal-computer-use[modal]"
```

The `modal` extra installs the supported Modal SDK. The base package does not import Modal until you use a Modal lifecycle operation.

Use `pip` if your project does not use `uv`:

```bash
python -m pip install "modal-computer-use[modal]"
```

## Set up Modal credentials

Run the Modal setup command:

```bash
uv run modal setup
```

Complete the browser flow that Modal opens. Then confirm that the CLI can access your Modal environment:

```bash
uv run modal environment list
```

Do not store Modal credentials in source files. Do not commit credential files.

## Choose optional extras

| Extra | Install command | Use |
| --- | --- | --- |
| Modal | `uv add "modal-computer-use[modal]"` | Create and attach to Modal Sandboxes |
| OpenAI | `uv add "modal-computer-use[openai]"` | Run an application-owned OpenAI model loop |
| Anthropic | `uv add "modal-computer-use[anthropic]"` | Run an application-owned Anthropic model loop |

You can combine extras in one install:

```bash
uv add "modal-computer-use[modal,openai]"
```

The provider adapters do not call model APIs. Your application owns provider credentials, model calls, and confirmation policy.

## Verify the install

```bash
uv run python -c "import modal_computer_use; print(modal_computer_use.__version__)"
uv run computer-use --help
```
