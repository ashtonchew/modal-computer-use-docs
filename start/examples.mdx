Primary examples use one async owner, one versioned handle, one explicitly placed Function, and one
borrow for each trajectory. Provider imports stay in application code.

Low-level examples remain useful for local execution, REST integration, idempotency, debugging,
and compatibility. Their callers establish and own topology explicitly.
