`modal-computer-use` gives your AI agents a real Linux desktop running inside Modal. You get a typed Python SDK with namespaces for every desktop operation — mouse, keyboard, clipboard, browser, screenshots, recordings, and file artifacts — all backed by a daemon that keeps state across turns.

## Get started in three steps

<Steps>
  <Step title="Install the SDK">
    Add `modal-computer-use` with the Modal extra using `uv` or `pip`:

    ```bash
    uv add "modal-computer-use[modal]"
    ```
  </Step>
  <Step title="Create a desktop">
    Use `ComputerSandbox.create()` to spin up a Modal Sandbox with a full Linux desktop:

    ```python quickstart.py
    from modal_computer_use import ComputerConfig, ComputerSandbox, BrowserConfig, ResourceConfig

    config = ComputerConfig(
        resources=ResourceConfig(profile="browser"),
        browser=BrowserConfig(kind="chromium"),
    )

    with ComputerSandbox.create(config=config) as computer:
        computer.browser.open_url("https://example.com")
        screenshot = computer.screenshots.full()
        screenshot.save("screenshot.png")
    ```
  </Step>
  <Step title="Run your script">
    ```bash
    uv run python quickstart.py
    ```

    When the `with` block ends, the SDK terminates the Sandbox automatically.
  </Step>
</Steps>

## Choose your interface

`modal-computer-use` provides three main entry points depending on your use case:

| Interface | Best for |
|---|---|
| `ComputerSandbox` | Synchronous scripts and notebooks |
| `AsyncComputerSandbox` | Async applications and Modal Functions |
| `AsyncDaemonClient` | Connecting to an already-running daemon |

See [Sync vs. Async](/concepts/async-sync) for guidance on choosing the right interface.
