Modal Computer Use gives Python applications a Linux desktop with screenshots, native input,
browser control, commands, and artifacts. The desktop runs in a Modal Sandbox. A colocated Modal
Function runs your model loop.

## Write the model loop

Your application owns model calls and conversation state. Borrow the desktop once, then use
`computer.step()` for each ordered action array.

```python
async with handle.borrow_async(
    run_id=run_id,
    function_region="us-west-2",
) as computer:
    screenshot = await computer.screenshots.full()

    while task_is_running:
        actions = await call_model(screenshot)
        result = await computer.step(actions)
        screenshot = result.screenshot
```

Step validates the complete array before mutation, runs the actions in order, and returns the action
results with an immediate screenshot. Your application decides when the target application is
ready and whether the task succeeded.

## Keep the trajectory close to the desktop

1. Create the desktop once with an async owner.
2. Send its session handle to a Function that declares the same supported region selector.
3. Keep one borrow and one pooled client for the model loop.
4. Release the borrow before the owner closes the desktop.

The [quickstart](/start/quickstart) shows the complete owner, Function, and cleanup flow.
