`modal-computer-use` ships first-class browser support through `BrowserConfig`. You can launch Chromium or Firefox, prewarm the browser before your workload starts, open URLs programmatically, inspect render performance, and persist profiles across sessions — all without leaving the Python SDK. This guide covers every `BrowserConfig` field and shows you how to build a complete browser automation workflow.

## BrowserConfig fields

Pass a `BrowserConfig` instance to `ComputerConfig.browser` to configure the in-Sandbox browser. All fields are optional; omitting `BrowserConfig` entirely means the SDK does not start or prewarm any browser.

| Field | Default | Description |
|---|---|---|
| `kind` | `None` | `"chromium"` or `"firefox"`. Unset falls back to `xdg-open` for generic URL opening. |
| `prewarm` | `True` | Start the browser at daemon boot so it is ready when your code runs. |
| `profile_dir` | `None` | Daemon path for the browser profile directory. Unset resolves at use time to `/home/desktop/.cache/modal-computer-use/browser-profile`. |
| `launch_args` | `[]` | Extra command-line arguments passed to the browser process. |
| `open_url_on_start` | `None` | A URL to open immediately when the browser starts. Takes precedence over blank-page prewarm. Treat this as a secret — do not log it. |
| `gpu_mode` | `None` | `"auto"`, `"off"`, or `"chromium-vulkan"`. The SDK resolves `None` to `"auto"`. |

## A complete ComputerConfig with BrowserConfig

The example below creates a prewarmed Firefox desktop with 4 CPUs and 8 GiB of memory:

```python
from modal_computer_use import (
    BrowserConfig,
    ComputerConfig,
    ComputerSandbox,
    ResourceConfig,
)

config = ComputerConfig(
    resources=ResourceConfig(
        profile="browser",
        cpu=4,
        memory_mib=8192,
    ),
    browser=BrowserConfig(
        kind="firefox",
        prewarm=True,
        launch_args=["--no-first-run"],
    ),
)

with ComputerSandbox.create(config=config) as computer:
    computer.browser.open_url("https://example.com")
    screenshot = computer.screenshots.full()
    screenshot.save("page.png")
```

When `prewarm=True`, the browser process starts during daemon boot. Your code does not need to wait for a cold browser launch — the browser is ready as soon as the Sandbox passes its readiness check.

## Opening URLs

Use `computer.browser.open_url(url)` to navigate the browser to any URL at any point after the Sandbox is ready:

```python
computer.browser.open_url("https://example.com")
computer.browser.open_url("https://docs.example.com/api")
```

If `open_url_on_start` is set in `BrowserConfig`, the browser opens that URL during startup instead of a blank page. You can still call `open_url()` later to navigate away.

## Checking browser status

Call `computer.browser.status()` to verify the browser is running and ready before you start interacting with it:

```python
status = computer.browser.status()
print({
    "ready": status.ready,
    "profile": status.resources.get("profile"),
})
```

`status()` returns the same object as `computer.status()` and includes resource profile information, so you can confirm that the profile and browser prewarm settings match your expectations.

## Render metrics

`computer.browser.render_metrics()` returns performance data from the running browser, useful for benchmarking page-load times or measuring rendering overhead:

```python
metrics = computer.browser.render_metrics()
print(metrics)
```

<Note>
Render metrics report the state the browser has observed so far. Call them after your page has loaded to get meaningful numbers.
</Note>

## GPU modes

GPU acceleration is opt-in. Use it only when page rendering is the measured bottleneck — it adds GPU allocation cost and requires the `browser-gpu` profile with an explicit `gpu` value:

<Tabs>
  <Tab title="auto (default)">
    The SDK resolves `None` to `"auto"`. The daemon selects the best available GPU mode for the configured browser.

    ```python
    browser=BrowserConfig(kind="chromium", gpu_mode="auto")
    ```
  </Tab>
  <Tab title="off">
    Disables GPU acceleration entirely. Use this for headless-style workloads where GPU availability is uncertain or unneeded.

    ```python
    browser=BrowserConfig(kind="chromium", gpu_mode="off")
    ```
  </Tab>
  <Tab title="chromium-vulkan">
    Enables Vulkan-backed GPU rendering for Chromium. Requires the `browser-gpu` profile and a GPU resource request.

    ```python
    from modal_computer_use import ResourceConfig

    config = ComputerConfig(
        resources=ResourceConfig(
            profile="browser-gpu",
            cpu=4,
            memory_mib=8192,
            gpu="T4",
        ),
        browser=BrowserConfig(
            kind="chromium",
            prewarm=True,
            gpu_mode="chromium-vulkan",
        ),
    )
    ```
  </Tab>
</Tabs>

## Profile persistence

Browser profiles hold cookies, cached site data, saved passwords, and extension state. By default the profile lives inside the Sandbox filesystem and is lost when the Sandbox terminates. You can persist it either by mounting a Modal Volume at the profile directory or by pointing `profile_dir` at the artifact directory that is already backed by a Volume.

<Steps>
  <Step title="Choose a profile directory">
    Set `profile_dir` to a stable path inside the Sandbox. This path is where the browser will read and write profile data.

    ```python
    PROFILE_PATH = "/home/desktop/artifacts/browser-profile"

    browser=BrowserConfig(
        kind="chromium",
        prewarm=True,
        profile_dir=PROFILE_PATH,
    )
    ```
  </Step>
  <Step title="Mount a Volume at the profile path">
    When creating the Sandbox, pass your Modal Volume v2 in the `volumes` dict keyed to the profile path (or a parent directory). Set `persist_artifacts=True` and call `computer.artifacts.sync()` after work completes.

    ```python
    import modal
    from modal_proto import api_pb2
    from modal_computer_use import ComputerConfig, ComputerSandbox, StorageConfig

    ARTIFACTS_DIR = "/home/desktop/artifacts"

    volume = modal.Volume.from_name(
        "browser-profile-volume",
        create_if_missing=True,
        version=api_pb2.VolumeFsVersion.Value("VOLUME_FS_VERSION_V2"),
    ).hydrate()

    config = ComputerConfig(
        resources=ResourceConfig(profile="browser"),
        browser=BrowserConfig(
            kind="chromium",
            prewarm=True,
            profile_dir=ARTIFACTS_DIR + "/browser-profile",
        ),
        storage=StorageConfig(persist_artifacts=True),
    )

    with ComputerSandbox.create(config=config, volumes={ARTIFACTS_DIR: volume}) as computer:
        computer.browser.open_url("https://example.com")
        # ... interact with the browser ...
        sync = computer.artifacts.sync()
        assert sync.ok and sync.persistent, "Profile sync failed"
    ```
  </Step>
  <Step title="Reuse the profile in the next session">
    Create a new Sandbox with the same `profile_dir` and the same Volume mounted. The browser finds its cookies and cache already in place.
  </Step>
</Steps>

## Full example: browser prewarm with optional GPU

The [`examples/browser_profile.py`](https://github.com/ashtonchew/modal-computer-use/blob/main/examples/browser_profile.py) example shows the complete pattern for switching between CPU-only and GPU-accelerated profiles:

```python
from modal_computer_use import BrowserConfig, ComputerConfig, ComputerSandbox, ResourceConfig


def browser_config(*, use_gpu: bool = False) -> ComputerConfig:
    return ComputerConfig(
        resources=ResourceConfig(
            profile="browser-gpu" if use_gpu else "browser",
            cpu=4,
            memory_mib=8192,
            gpu="T4" if use_gpu else None,
        ),
        browser=BrowserConfig(kind="firefox", prewarm=True),
    )


def main() -> None:
    computer = ComputerSandbox.create(config=browser_config(use_gpu=False))
    try:
        computer.wait_until_ready()
        computer.browser.open_url("https://example.com")
        status = computer.status()
        print({
            "ready": status.ready,
            "profile": status.resources.get("profile"),
            "browser_prewarm": True,
            "gpu_enabled": False,
        })
    finally:
        computer.terminate()
        computer.detach()


if __name__ == "__main__":
    main()
```

Run it with:

```bash
uv run python examples/browser_profile.py
```
